## Sobre o projeto

Este repositório contém os microsserviços desenvolvidos em aula e na atividade:

- `product-api`: microsserviço de produtos, construído em sala de aula (porta 8000).
- `currency-api`: microsserviço de cotação de moedas, desenvolvido nesta atividade (porta 8100).
- `start_consul.bat`: script que inicia o HashiCorp Consul local e cadastra as configurações dos microsserviços.

## Tecnologias

Java 21, Spring Boot, Spring Data JPA, PostgreSQL, Flyway e HashiCorp Consul.
